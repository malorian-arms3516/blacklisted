
# Blacklisted: Most Wanted Information Directory

Blacklisted is an information directory containing information from the 2005 game Need for Speed: Most Wanted, particularly vehicles and blacklist members.

Information gathered in this directory can be found within the [Official NFS Wiki](https://nfs.fandom.com/wiki/Need_for_Speed_Wiki/), Wikipedia sites of specific vehicles, or within the actual game itself. I do not own any of the trademarks or media found within this project. This project is solely for educational purposes only. No profiteering or unlawful reproduction is allowed. 

# What is this project for?

I am developing this project as a way to learn web design through Python. I have been able to create web applications in the past using PHP and MySQL, and I would like to be able to learn and use other tools that allows me to create dynamic and efficient web applications.

# What can I find in this project?

Information such as specific vehicle details, or character background and story details can be found within this directory. Additional vehicle details for addon car mods will eventually be added, and a modding section will be implemented down the road.
